# 图文共同构图

先在分镜记录正文、文字框位置、人物动作、关键道具、阅读顺序和前后连续性，再生成插画。让墙面、天空、地面或自然留白承载正文，插画延伸到文字周围，组成连续场景。

整本构图先定视觉节奏，再定单页镜头：每页只服务一个主要视觉任务，景别和视角的变化必须回应故事动作、科学证据或情绪转折。相邻页重复时先做相邻页重复审计；只有为了科学对照、观察停顿或翻页钩子而保留的有价值的重复，才继续使用相似构图。

每页 text_box_mm（文字框）应与该页构图对应；根据动作变化选择上方墙面、下方地面或侧面留白，不机械轮换，不用统一矩形图块加统一正文块。文字至少保持默认22磅和安全边，保留完整朗读内容；容不下时调整构图或拆页。

给图像生成工具明确：完整纵向单页、人物和道具位置、需要低纹理浅色留白的具体区域、该处后续放多少行文字、无印刷字、无正文框。先检查图像，再在留白内排可编辑正文。文本区域属于插画场景，文字层与图像层在技术上分开以保证缺字、准确性、溢出和打印校验。

只在实际查看留白和图文叠合效果后，将 text_area_reviewed（文字区域已检查）设为 true（已确认）。进行 text-image state matching：正文所说的人物、道具数量、位置、动作、时间顺序和知识条件必须与本页实际画面相符；不以提示词代替观察证据。检查脸、手、分类结果和知识关键物不被遮挡，低纹理区域对比清楚，阅读顺序无歧义。打印有纸边白边不影响页内图文融合。

生成分辨率应按最终画面尺寸计算。优先请求足够原生像素，不通过放大低分辨率图或修改分辨率元数据冒充高清。

封面、封底与故事页采用共同构图。家长说明和打印提示默认独立成文件，不进入儿童阅读版或家庭打印版；仅在用户明确要求时附在故事之后。保存用户认可的样页及其布局作为项目参考，不在技能资源中存入用户插画。

## 逐页版式设计与三种模式

正式生成插画前，为每页填写 `layout_design`，至少锁定以下信息：`layout_style_version`、`layout_mode`、`text_anchor`、`text_treatment`、`text_align`、`max_lines`、具体 `focal_point`、`text_safe_area`、`avoid_covering`、`page_rhythm`、`palette_token` 和 `status`。`text_box_mm` 是版面执行坐标，`text_safe_area` 是给图像生成阶段看的自然区域说明；二者要能互相核对。正文很长时先调构图或拆页，不能等生成后压小字号。

三种模式的选择必须有页面理由，并保持同册颜色、边距和字体层级一致。当前新小红书生产只允许 `scene-integrated`；另外两种模式只为历史项目复核保留：

- `scene-integrated`：适合天空、墙面、地面、桌面等低纹理自然留白。没有明显字幕框，正文进入已锁定的留白，画面延展到文字周围。
- `soft-card`：适合背景复杂但仍要保持场景连续。使用圆角、低对比边界和本册批准的纸张色；文字卡不得盖住脸、手、关键道具或视觉焦点，也不使用默认白色矩形。
- `narrative-band`：适合动作密集、没有足够自然留白的历史页面。在画面中段或侧面设置连续叙事带；当前新小红书页面不启用此模式。

生成前的提示词必须写清：完整竖版单页、主体和环境覆盖主要画面高度、背景从上到下连续延展、人物和道具位置、画面内部文字安全区的方位与纹理、预留行数和不可遮挡对象。图像不得生成文字、伪文字、字母或正文框，也不得生成横向条幅、上下大块空白或底部通栏；正文由排版层后置加入。这里的“技术分层”是为了保证文字可编辑、可提取和可校验，不等于视觉上把画面和字幕割裂。成页需要“视觉融合”：文字应像场景中的自然留白、画面内的柔和文字卡或连续叙事带的一部分。

生成后逐页实际查看并记录 `layout_review`：文字是否仍在安全区、对比是否足够、是否遮挡脸/手/关键物、阅读顺序是否明确、人物和前后页动作是否连续。字段完整或脚本通过，只能说明确定性条件满足，不能声称自动审美通过。

## 社媒 profile 的构图分层

用户明确选择小红书静态图文时使用 `xiaohongshu-feed-3x4`，画布为 `1080×1440`，源图比例为3:4。该分支的新小红书页必须同时声明 `composition_mode: portrait-full-bleed` 与 `text_placement: in-scene`，文字安全区位于插画内部，不能使用底部通栏或大块不透明文字卡。默认无字交付仍可复用同一3:4源图画布契约，但不渲染文字、不创建社媒成品。可以复用角色、主色和道具状态，但必须按目标画布重排视觉焦点、主体安全区和文字安全区，不直接缩放、中心裁切或补大块空白。底层代码仍兼容旧9:16项目，但不属于默认页面生产范围。技术分层不等于视觉割裂：明确要求图文成品时，最终文字与插画必须在同一张扁平化社媒图内融合，自动几何检查不替代人工/模型审美审核。
