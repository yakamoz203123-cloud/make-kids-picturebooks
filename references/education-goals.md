# 教育目标卡

教育目标卡是每册绘本的内容边界和阅读观察契约，不是给孩子做的考试。它必须在正式分镜前完成并经过内容核对；六个必填字段没有实际内容时，停在规划阶段，不写正式分镜、不生成正式插画。

从 [教育目标模板](../assets/education-goal-template.json) 复制一份到私有项目，保存为 `education-goal.json`。保持 `schema_version: 1`，将 `status` 从 `pending` 改为 `approved` 只表示目标卡已完成核对，不表示孩子已经理解知识。

| 字段 | 必须回答的问题 | 合格形态 |
| --- | --- | --- |
| `core_knowledge` | 本册只让孩子接近哪一个核心知识？ | 一句可核验的知识关系，不写成泛泛主题 |
| `target_age_band` | 面向哪一个年龄档？ | 只能是 `3-4`、`5-7` 或 `8-10` 之一 |
| `prior_experience` | 孩子可能已经见过什么具体生活经验？ | 可观察的经验，不假设孩子读过成人原书 |
| `visible_relationship` | 故事用什么行动和结果把知识关系演出来？ | 具体人物行动、变化和可见结果 |
| `knowledge_boundary` | 哪些推断、类比或结论不能从本册得出？ | 明确的边界和不应暗示的过度结论 |
| `reading_observation` | 共读时观察什么，而不是考孩子什么？ | 一个开放的家庭观察提示或生活延伸 |

先检查来源事实和年龄，再填写目标卡。`visible_relationship` 必须能映射到后续分镜中的人物动作、道具状态或环境变化；只有“讲清楚”“认识科学”之类的抽象目标不合格。`knowledge_boundary` 用来防止故事把一次具体观察夸大成普遍规律。对于3—4岁，优先使用“具体场景—人物行动—可见结果”，减少抽象解释；对于5—7岁和8—10岁，仍然只保留本册能够用画面和故事支持的关系。

目标卡完成后，故事可以保持轻松、原创和非说教。`reading_observation` 只用于家长共读后的真实观察，例如“孩子能否说出两个人分别做了什么”，不能改写成分数、通过率或模型推断。实际共读尚未发生时，在验收记录中标为 `pending`，不能把目标卡当成真实阅读证据。

目标卡与后续证据分开保存：工程检查证明文件和流程可复现，内容检查证明知识与故事一致，视觉检查证明成页可读且连续，真实阅读证据只记录实际家庭阅读反馈。四类证据不能互相替代。
