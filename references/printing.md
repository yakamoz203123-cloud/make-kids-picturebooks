# 历史家庭打印与脚本数据

本文件只服务于用户明确要求的历史家庭打印分支。当前默认只交付 `pure-images` 无字源图和独立正文；可阅读小红书静态图文、PDF、拼版或第二套成品都必须明确请求。不会因为复制本文件或使用 `book-template.json` 就自动生成 PDF 或拼版。只有用户明确要求打印时，才在独立版本目录中按本文件执行，并保留默认交付不被覆盖。

默认A4（210×297毫米）横向双面打印，每面两页，对折中缝装订。阅读版固定为A5（148×210毫米），含封面封底页数为4倍数；`validate_exports.py` 会拒绝其他阅读页尺寸。按完整故事的自然节奏选择8、12、16、20等合适页数，不将16或20页当成默认目标。优先调整有意义的故事分页，如拆开请求与回应；可使用有用途的扉页或封底，不以家长说明或机械总结补齐页数。

版面文件采用 assets/book-template.json，页码从1连续排列。故事页默认采用图文融合：正文放在连续场景的自然留白内；矩形 `image_box_mm`（图像框）及 `text_box_mm`（文字框）均为左下角横坐标、纵坐标、宽、高，单位毫米。没有图像的扉页或说明页省略 image（图像）字段；需要无字页面必须将 `text`（正文）设为空字符串，并明确标记 `kind: "blank"` 或 `wordless: true`，不能用未标记的空正文绕过检查。默认正文字体22磅，封面可设置每页 font_size（字号）形成标题层级；白边至少10毫米，说明过长则拆页，不用小字挤入。

默认附带中文打印字体，覆盖常用汉字及中文标点，使用许可见 assets/font-license.txt。遇到罕见字时另指定字体。自定义字体必须指向可嵌入的TrueType（真实字形）轮廓字体文件，支持实际正文中的全部字符；脚本检查缺字和嵌入限制。字体集合或CFF（紧凑字体格式）轮廓可先用 scripts/prepare_font.py 生成当前正文字符的可嵌入子集：python3 prepare_font.py 字体来源 正文文本 输出字体 --face-index 2；字体面编号须按实际来源确认，不默认所有集合都是2。不得绕过字体许可限制。无法取得时保留版面数据并报告阻碍。不能以未嵌入的中文系统替代字体冒充已通过。

图像保持比例居中，不自动裁切。以最终放置尺寸计算有效分辨率，默认300像素／英寸。仅在用户明确选择并记录 quality_approval 时采用 home-pilot 家庭试制档位，门槛不低于200；详见 acceptance.md。不修改元数据伪装高清。文字和关键人物、道具不能遮挡。故事页设置 image_role（图像角色）为 background（场景背景），文字框可以位于图像框内；必须实际查看留白、对比和遮挡后设置 text_area_reviewed（文字区域已检查）为 true（已确认）。普通 inset（独立插图）仍禁止图文框重叠。各框均不能超出安全边。

脚本拒绝覆盖现有输出；新版放在新版本目录。render_book.py（阅读版脚本）先验证所有页面，再生成；impose_booklet.py（拼版脚本）将单页阅读版拼成A4横向并为家用机留5毫米纸边。拼版会适当内缩页面，因此成品有效画面略小于阅读版；保留纸张白边即可，不要求裁切。

打印指导须包含：

- 打印已经拼好的文件，选A4、横向、实际大小，关闭打印软件的“小册子”二次拼版。
- 自动双面先测试短边翻转，只试打一张纸；不同打印机方向以试打为准。
- 无自动双面时先标记一张测试纸的上边和正面，试验重新进纸方向，再分正反面打印；不要猜机器进纸方向。
- 每张纸的两面按文件连续打印，按纸张顺序从外到内套叠，对折并中缝装订，检查封面及连续页码。
- 家庭装订由成人完成。第一册实物检查字号、清晰度、颜色及书脊，再给孩子试读。

文字缺字、溢出、关键画面低清或拼版不正确时停止成品交付并修复。最终导出前后检查可嵌入字体、许可证和来源路径，以及阅读版、打印版的可提取文字和最低打印字号。脚本验证不替代渲染逐页检查，不替代用户实物反馈。

## 版式执行和审美复核

每个新版式页必须带完整的 `layout_design`。先在 `text_box_mm` 中确定正文区域和最大行数，再选择 `scene-integrated`、`soft-card` 或 `narrative-band`；不要把后置字幕默认放在白色矩形里。正文仍保持可编辑、可提取的文字层，插画层不生成文字；两层在技术上分开，在视觉上通过自然留白、柔和文字卡或连续叙事带融合。

导出前后都要实际查看逐页 PNG，并保存 `layout_review`：检查文字是否处于已锁定的安全区、背景对比是否足够、文字卡是否遮挡脸/手/关键道具、阅读顺序是否清楚，以及相邻页的人物状态和页面节奏是否连续。确定性脚本通过、字体嵌入或文字可提取，只能证明技术条件，不代表审美通过。

## 社媒竖屏另行输出

小红书和抖音的版本都不是打印 PDF 的裁切副本，且只在用户明确选择相应社媒成品时生成。小红书使用 `xiaohongshu-feed-3x4`、`1080×1440`、3:4 源图；抖音/长屏才使用 `social-vertical-9x16`、`1080×1920`、9:16 源图。一次导出只绑定一个 profile；同时交付两个 profile 时分别建立 profile-specific 输出版本、源图和逐页审核记录，不直接缩放/中心裁切；不能把横向图塞入竖屏后补大块空白。社媒分支要在生成前记录主体安全区、字幕安全区和平台界面避让区，单独输出逐页 PNG/JPEG；源图比例不符时拒绝导出，也不能用印刷版已通过来替代社媒版逐页审核。社媒字幕允许按平台需要栅格化，印刷 PDF 仍必须保留可提取文字层。
