# 制作检查

逐册保存检查记录：检查项、结果、具体页码、证据文件、待修问题、修订次数。缺陷未解决时不能标记数字检查通过。

0. 年龄：明确所选3—4岁、5—7岁或8—10岁；只审核本次要求的年龄版本，核对行动、因果、比较和阅读问题符合所选创作策略，项目、册与清单年龄一致。旧册5—6岁保留原标记和适用范围。
1. 知识：来源可定位、关键条件保留、概念卡及故事因果一致、类比边界明确；记录故事事件为何体现概念及必须出现的视觉证据，并核对实际画面，不能只写“科学通过”。
2. 故事：通读整册确认家长无需临时补话也能讲完；正文不是图片标签。核对无页码的完整朗读稿：愿望明确、行动有因果、态度变化有可见触发、结尾回应开头；不能以“过了一会儿”或知识总结掩盖转场缺口。朗读顺畅、角色有愿望和行动、目标年龄的孩子可跟随情节、无硬加说教；8—10岁版同时支持自主阅读。
   分页：核对每页分镜的叙事用途，并实际做删除／合并检查，记录保留或调整的理由。安静观察和情绪停顿可以保留；对故事、节奏和观察均无贡献的页先改写、合并或删除。不能因总页数为4倍数、文字不溢出就判断该页通过。
3. 图像：固定人物一致，物体数量可数，结构及变化准确，前后道具连续；核对逐页数量、位置、状态、变化，清单所选图与版面实际图一致，正文版本与文字区域一致。
4. 版面：检查文字在场景自然留白内，与画面共同构图，位置随事件变化，不能每页固定上图下文；家长说明默认另存文件；未明确要求时，检查儿童绘本内没有制作说明或凑页数的总结。渲染每个阅读页和打印面并查看；无缺字、溢出、遮挡、重叠或书脊关键信息。中文逗号、句号、闭引号等不置行首，开引号等不置行末；孤立标点调整可编辑断行，保持正文舒适字号。压缩导出后再次核对字体和中文文字提取，不能仅凭画面可读就通过。
   审美：按艺术指导核对风格卡与实际成页。整册角色、道具、材质和主色连续；视觉焦点清楚，表情可读，花草及纹理不抢正文和关键动作；远近景、安静与行动形成节奏。同场景多风格对照仅证明方向探索，不计为整册插画完成。
5. 技术：字体嵌入、页数尺寸、有效图片分辨率、拼版每页恰好一次与折叠顺序。
6. 续做：核对实际成果是否存在，状态与成果一致；变更来源或角色先重新核验。
7. 实物：先一张纸测试方向，再整册折叠装订；用户反馈后才标记试打通过。

数字检查可在环境中完成；纸张、双面方向、颜色和宝宝试读必须基于真实反馈。不宣称已完成不可观察的环节。
