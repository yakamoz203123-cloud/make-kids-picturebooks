# 适龄选题筛选

从书中找到值得为孩子讲的概念。先选择年龄，再筛选已核验内容；原书是知识来源，章节是定位线索。册数由已选概念和本次制作范围决定。摘取的是概念，绘本正文和故事保持原创。

## 筛选步骤

1. 查看目录、导言或相关片段，识别可能贴近孩子生活的主题。长书允许分段筛选，保存实际读取范围；目录中的线索先标为candidate（待核验）。
2. 实际读取候选概念及成立条件，不只凭标题或一句摘录判断。按年龄检查：孩子能观察什么、能做或比较什么、需要哪些前置经验、故事动作能否准确体现概念、简化会丢掉什么条件。涉及危险操作时换成安全观察或暂缓。
3. 去掉重复主题，把紧密相关、支持同一概念的片段跨章节整合。缺少前置经验时先铺垫，过于抽象或故事无法承载时暂缓或跳过，记录理由。允许整本提供的内容都没有适合本次年龄的主题。
4. 通常先提出3—5个有依据的候选；只有少量适合时如实给出，不凑数量。用“主题、儿童可发现的事、适龄理由、来源位置、前置经验、建议册数”说明推荐。另简要记录重要暂缓或跳过项，不要求逐章列满评估表。
5. 按儿童所需铺垫、难度及已有兴趣排序，确定优先推荐册。用户选定主题或范围时直接采用；没有指定制作范围时先做一册，其他适龄主题保留为候选池，不自动变成制作任务。用户要求多册时才把对应册全部加入本次队列。

## 项目记录

新项目 adaptation_mode（改编模式）为selected_topics（适龄主题筛选）；用户明确要求按章推进时才保存chapter_order（按章模式）。source.chapter_index（来源章节索引）用于追踪阅读情况和出处，在主题模式下不驱动下一册。

topic_selection（主题筛选）保存本次单一 age_band（年龄段）、pending（待筛选）或ready（筛选已完成）状态、topics（主题记录）与queue（本次待推进的册编号，有序）。主题记录保存id、title、source_locators、child_goal、prerequisites、reason、status及book_ids。status分别为candidate（待核验）、selected（适龄且已核验）、deferred（暂缓）和skipped（跳过）。本次队列只包含selected主题的册编号。适龄候选池可以较多，本次队列通常只有优先推荐的一册。

```json
{"adaptation_mode":"selected_topics","topic_selection":{"age_band":"3-4","status":"ready","topics":[{"id":"t01","title":"一起接力做纸花","source_locators":["第四节，工序交接段落"],"child_goal":"看见同一朵花经过不同人接续完成","prerequisites":["熟悉拿放和交接"],"reason":"动作及物体变化可见，能用一个生活故事表达","status":"selected","book_ids":["b01"]},{"id":"t02","title":"形式化约束","source_locators":["第一节，公式定义"],"child_goal":null,"prerequisites":["理解抽象符号"],"reason":"本次年龄缺少前置经验，故事化容易改变定义","status":"deferred","book_ids":[]}],"queue":["b01"]}}
```

示例只展示结构，不是固定选题或对所有孩子的能力判断。年龄更改后重新筛选，不只改标签。发现来源未核验时保持candidate；不得为了通过队列检查而把暂缓或未读主题直接改成selected。

## 续做

继续现有项目时先核对本次主题队列和实际文件。完成一个册后只推进队列中的下一册；队列结束只代表本次制作范围完成，不要求补齐全书。用户说“再做一册”时从未完成的已核验适龄主题中推荐下一项，更新队列；需要新增主题时先筛选并读取实际上下文。用户点名旧册修改时可将该册加入队列，保留旧版本。

旧项目没有改编模式时脚本保留原行为。执行者按当前用户偏好更新模式和筛选记录，历史作品保留；原来的章节建议不能直接作为新模式的自动制作队列。
